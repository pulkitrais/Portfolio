# Pulkit Rai - Cybersecurity Engineer Portfolio

The official portfolio website for Pulkit Rai, hosted at [pulkitrai.tech](https://pulkitrai.tech).

## Overview

Designed with modern dark cyber aesthetics, ambient aurora gradients, interactive card spotlights, and a real-time SOC telemetry simulation console.

## Features

- **Interactive Telemetry Workstation:** Live terminal simulating Microsoft Sentinel KQL query execution, alert correlation, and MITRE ATT&CK cloud mappings.
- **Dynamic Project Showcase:** Filterable project cards with category tabs (Cloud Security, SOAR Playbooks, Systems Research).
- **Interactive Mouse Spotlight:** Smooth card edge illumination based on cursor position.
- **Laser Career Timeline:** Chronological progression of security engineering experience and research.
- **Zero-Dependency High Performance:** Built with clean semantic HTML5, modern CSS variables, and lightweight JavaScript.

## Local Development

Open `index.html` directly in any web browser, or serve locally with Python:

```bash
python3 -m http.server 8080
```
