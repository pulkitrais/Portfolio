## Why I built this lab

I wanted a hands-on environment where I could practice **real SOC workflows** instead of only theory.  
The goal was simple: ingest logs, detect threats, and automate response.

## What I used

- Microsoft Sentinel
- Log Analytics Workspace
- Azure Monitor Agent
- Data Collection Rules (DCR)
- Syslog + Windows event sources

## Core workflow

1. Onboarded endpoints and data sources.
2. Normalized and verified incoming telemetry.
3. Created analytics rules for high-signal detections.
4. Routed detections into incidents for triage.
5. Connected SOAR playbooks for response actions.

## Biggest lesson

Detection quality depends on **clean ingestion + tuning**, not only writing queries.
Once logging quality improved, false positives dropped and alerts became actionable.
